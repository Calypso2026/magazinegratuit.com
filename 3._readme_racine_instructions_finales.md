# 🚀 Dossier 3 : CONFIGURATION RACINE & README

C'est l'étape la plus importante. Ces deux fichiers doivent être à la racine même de votre projet (en dehors des dossiers frontend et backend).

---

### 📄 Fichier 1 : `package.json` (À LA RACINE)
```json
{
  "name": "magazine-gratuit-root",
  "version": "1.0.0",
  "main": "backend/server.js",
  "scripts": {
    "install-backend": "npm install",
    "install-frontend": "cd frontend && npm install",
    "build-frontend": "cd frontend && npm run build",
    "build": "npm install && npm run install-frontend && npm run build-frontend",
    "start": "node backend/server.js"
  },
  "dependencies": {
    "express": "^4.18.2",
    "mongoose": "^7.0.0",
    "cors": "^2.8.5",
    "dotenv": "^16.0.3"
  }
}
```

---

### 📄 Fichier 2 : `README.md`
```markdown
# MagazineGratuit

Plateforme de bibliothèque numérique moderne avec interface responsive, animations fluides et gestion sécurisée.

## 📁 Structure du projet
- `/backend` : Serveur Node.js / Express et connexion MongoDB.
- `/frontend` : Interface React avec Tailwind CSS et Framer Motion.
- `package.json` : Fichier de configuration racine pour Render.

## 🛠️ Déploiement sur Render
1. Liez votre dépôt GitHub à Render.
2. Type de service : **Web Service**.
3. **Build Command** : `npm run build`
4. **Start Command** : `npm start`
5. **Variables d'environnement** :
   - `NODE_ENV` : `production`
   - `MONGODB_URI` : `votre_lien_atlas_mongodb`
```
