# 📚 Dossier 1 : FRONTEND (Interface Utilisateur)

Pour votre dossier `frontend/`, vous avez besoin de trois fichiers principaux. Créez un dossier nommé `frontend` à la racine de votre projet GitHub, puis placez-y ces fichiers :

---

### 📄 Fichier 1 : `frontend/package.json`
```json
{
  "name": "magazine-gratuit-frontend",
  "version": "1.0.0",
  "private": true,
  "dependencies": {
    "react": "^18.2.0",
    "react-dom": "^18.2.0",
    "react-router-dom": "^6.10.0",
    "lucide-react": "^0.263.1",
    "framer-motion": "^10.12.16"
  },
  "scripts": {
    "start": "react-scripts start",
    "build": "react-scripts build"
  },
  "devDependencies": {
    "tailwindcss": "^3.3.1",
    "react-scripts": "5.0.1"
  }
}
```

---
